## 发现并修复的问题

1. **原生配置表单完全没样式。** 字段标签和数字框挤成一行（`min samples for an interval[3] max actionable fixes per report[3] bootstrap…`），无法扫读。原因：设置表单用了 `.sev-settings-*` 类，但样式表只在回合卡/弹窗里注入。
   修复：`SettingsForm` 自己注入样式表。
2. **中英混排。** 分组标题是中文（评分权重与阈值 / 成本 / …），字段标签却是英文（`min samples for an interval`、`token budget per load`）。
   修复：设置 API 返回 `labelZh`，客户端按 `useLang().lang` 选择；分组标题也随语言切换。
3. **表单横跨整个内容区**（约 1160px），标签与输入框隔太远。
   修复：`max-width: 720px`，两列 `minmax(200px,1fr) / 180px`。
4. 顺带确认：面板标题「技能评测」、计数「6 个技能有遥测 · 3 个有待修问题」、刷新/复制按钮、四个标签在真实界面都正常。

## 1.20.1 复查：右上三个按钮 + MCP / 开发者标签（2026-11-17）

方法：真实宿主路由（`curl`）+ 用 jsdom 挂载**线上真实载荷** `/skill-eval/data/1.20.1`
后逐个点击、切标签；宿主侧再用 `scripts/verify-live.mjs` 对照。不是截图，也不是只看代码。

| ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 配置         | 旧实现 `window.open('/skill-eval/board/<v>/config')`。DSH 桌面壳的 `setWindowOpenHandler` 只把 **https** URL 交给系统浏览器，其余一律 `deny`，而看板跑在 `http://127.0.0.1:<port>` → 点击**完全没有反应** | **已修**：改为面板内设置弹窗（复用 `SettingsForm`），Esc/点背景关闭，Tab 焦点限制在弹窗内；桌面壳里隐藏无法兑现的「在网页里打开」      |
| 刷新         | 点击后重新 GET `/skill-eval/data/<v>`，loading 期间禁用                                                                                                                                                   | 正常                                                                                                                                   |

`node --test test/` **258 项全绿**（新增「配置按钮不再调用 window.open，改为面板内表单」用例）。

已知取舍（未改）：**「复制给 agent」复制的是完整 JSON**（≈250KB，含 400 条步进记录）。
如果目标是让 agent 直接读，`buildMarkdown()` 的摘要更省上下文；但完整 JSON 便于排障，
两者取舍需产品确认，暂保持现状。

## 仍然存在的体验问题（未改，先记录）

- **插件详情页正文是英文 README**，而界面是中文；DSH 目前渲染 `README.md`。若要中文详情，需要额外提供本地化正文（还没做，需确认 DSH 的本地化机制）。
- ~~看板里的建议正文仍是英文~~：1.17.4 起规则建议的标题与修复为中文；1.17.5 起排名提示与效度断言也为中文。仅 evidence 中的测量 id/数字保留英文（数据本身）。
- **配置表单在 README 之后**，需要向下滚动较深才能看到；DSH 的 bundle config 位次就是"描述与组件之间"，这是平台布局，不是我们能任意移动的。
- 插件市场/已安装列表**很长且无搜索**，找某个插件要滚动很久（平台行为）。
- 原生设置页的版本号显示的是插件市场里记录的快照（截图时 1.17.0），与热重载后的源码版本可能短暂不一致。
- 面板里的建议标题/证据/修复仍是英文，与中文界面混排。
