# 多维度审计 · Multi-angle audit (1.18.0)

Four parallel read-only audits plus the root agent's own probes covered the host
data pipeline, the HTTP/rendering layer, the client UI and packaging/docs. Every
finding below was reproduced against the real modules before a fix was written;
the fixes have regression tests (`test/audit-regressions.test.js`, `test/store.test.js`,
`test/settings.test.js`, `test/client.test.js`).

## Verification

- `node --test test/` → **232 passing** (215 before this audit; regression tests for every fixed finding plus CLI exit codes, EN locale coverage, settings group metadata and client build helpers).
- Live host after hot reload: `/skill-eval/data/<version>` JSON, `accept` 17/17, `verify` 9/9.
- Live security probes: cross-site `Origin` POST → **403**; missing `x-skill-eval-config` → **403**; 70 KB form body → **413**; same-origin GET unchanged.
- Clean profile install of the packed tarball: accept 17/17, verify 9/9.

## Follow-up findings from the architecture audit (also fixed)

- **Versioned pages rendered canonical links** (high): `/board/<v>` posted its form to `/config` and linked there, so a hot reload saved into the stale generation. Each page route now renders against its own base; regression test checks the versioned `action` and link.
- **English TEXTS were missing the new localization keys** (medium): the EN turn strip rendered `undefined`; keys restored and a test renders the EN strip asserting no `undefined`.
- **Threshold repair collapsed bands** (medium): `{90,50,70}` became `{90,50,50}`; floors are now sorted descending. Settings bounds now match the Config schema (`windowTtlMs` added, 25 fields).
- **Custom `dashboardPath` broke the client**: data/settings routes now stay under the fixed `/skill-eval` client contract while pages follow the configured path.
- **Silent telemetry write failures**: `EventStore.onError` logs once and the board shows `telemetry write failed`.
- **Dead code**: removed unused `MoreMenuBoard`/`PluginDetailSection`, `GRADE_BANDS`; rendered loop budget now follows `scoring.editBudgetMax`.

## Deferred / residual

- Store rotation/compaction is still absent. The report cache removes the repeated
  cost, but a very long-lived profile keeps every record. A future version should
  roll `events.jsonl` monthly or keep N windows per skill.
- DNS-rebinding **read** protection belongs to the DSH host's trust layer; this
  plugin now fences writes only.
- Client still loses scroll position when the main panel unmounts, and long
  skill lists are not virtualized (121-card probe: ~89 ms first paint in jsdom).
- Threshold ordering (`excellent ≥ good ≥ pass`) is repaired at scoring time but
  not rejected at write time; settings `mcpErrorRatePercent` allows 0 while the
  Config schema requires ≥1.
